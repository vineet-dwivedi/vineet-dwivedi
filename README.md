## About

I'm an engineer who likes building systems where the interesting part isn't the UI — it's what's running underneath: agent orchestration graphs, streaming pipelines, and the plumbing that keeps them fast under load. My work sits at the intersection of full-stack product engineering and applied AI. I've shipped video-intelligence tools, multi-agent frontend generators, and real-time search engines, typically built on Python/FastAPI or Node backends talking to LangGraph/LangChain agents, with MongoDB, PostgreSQL, or Redis doing the heavy lifting behind them.

I'm currently looking for **SDE-1 / Full-Stack & AI Engineer** roles on teams that move fast and care about the engineering as much as the product.
